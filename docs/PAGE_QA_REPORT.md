# 全项目清理与回归记录

日期：2026-10-26。范围包含前端 33 个业务页面及其组件、API 和状态模块，后端 209 个 Java 源文件，以及启动、测试、部署配置。检查调用关系、重复实现、废弃分支和跨模块业务流程；不以文件行数直接判断代码是否可删。

## 已完成的收敛

| 范围 | 清理与实际影响 |
| --- | --- |
| 全局 Agent | 普通指令统一交给模型理解，规则仅作不可用时的兜底；业务执行共用任务运行器。删除聊天内独立的急救定位、候选查询、提交与专用表单，进入现有呼救页自动定位。模型上下文补齐已选提醒、联系人、报告、稿件和账户的类型，避免选中对象后重复列出列表。 |
| 设备与选点 | 删除设备页独立地图弹层、搜索和销毁逻辑，统一使用公共选点页；保留地点搜索、地址回填、带入已有坐标和取消保留草稿。H5 与原生选点不再同时启动。设备录入页由 1423 行降至 989 行。 |
| 健康与穿戴 | 删除绑定成功后仍提示去 iOS App 的遗留分支及重复解绑调用；H5 扫描不调用原生 BLE。切换账号或退出时清空健康缓存并停止旧蓝牙订阅，旧请求不能覆盖新账号，较早刷新结果不能覆盖较新结果。 |
| 公共业务数据 | 统一分页响应、科普分类、设备状态展示及距离计算。补齐设备界面已有的周末服务时段；本机样例移动设备服务范围改用接口约定的公里。 |
| 后端业务与持久化 | 活动救援状态统一由领域枚举提供，查询与状态机共用定义；删除设备和心率仓库中 4 个无调用查询。保留业务权限、事务锁和 Flyway 历史迁移。 |
| 报告与文档 | 报告上传页与 Agent 共用外发授权流程；未授权时就地说明百度 OCR 用途，确认后复用原图继续，拒绝时保留手动录入。文档报告提取统一到后端，与 OCR 共用结构化逻辑；普通文档上传后自动阅读，可复用原文件追问或投稿。缺失日期、机构和单位不猜测。 |
| 发布配置 | 发布脚本不再重写 JWT、AI/OCR 凭据、CORS 或迁移 Nginx 旧文本。首次配置使用独立模板；静态资源先解包并检查入口文件，通过后才停止应用。详见 [部署说明](../deploy/README.md)。 |
| 自动检查 | 修正旧测试对联系人姓名、预览坐标和 OCR 关闭状态的假设。OCR 不可用分支在浏览器中注入明确失败响应，不依赖本机是否配置有效凭据。 |

未发现可仅凭静态引用直接删除的孤立页面、组件或后端业务类。地图双 SDK、定位失败时的手动选点、健康报告人工录入属于有效降级路径，予以保留。

## 验证边界

代码清理回归未生成移动端安装包。随后按用户要求生成 H5 与服务端 JAR，部署至公网独立环境；入口、实际检查和运维信息见 [部署记录](../deploy/README.md)。本轮未生成 APK 或 IPA。BLE 的协议解析和清理使用模拟原生 API 验证，实际连接、断连、定位和系统权限仍需 Android/iOS 真机验收。

后端测试和本机演示使用独立 H2；公网部署另在 MySQL 8 空库实际通过 17 个迁移及业务检查。公网只创建管理员及明确需要的测试账号，未复制本机业务数据；杭州固定位置与场景数据仅用于本机预览。H5 生产构建和公网运行已验证。
