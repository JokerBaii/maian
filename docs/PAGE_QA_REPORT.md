## 浏览器实抓范围

使用 Chromium 以 `390 × 844` 移动视口逐页打开 `src/pages.json` 注册的全部 29 个页面，并按业务权限分别使用普通用户、救援志愿者和平台审核员身份。救援详情额外检查施救端状态；生命响应台和施救端详情另以 `375 × 667` 小屏复核，共 32 个检查点。

检查项包括：

- 页面可访问且主体内容非空；
- 页面标题与业务场景一致；
- 无未登录回退、空白页或异常中断；
- 同源 API 无 4xx/5xx；
- 浏览器控制台无错误；
- 页面无横向溢出；
- 首屏主任务和关键操作未被裁切；
- 地图、ETA、双方联络、AED 交接、现场处置与完成确认的层级清晰。
