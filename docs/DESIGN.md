# 脉安驰援设计规范

## 1. 设计目标

脉安驰援服务两种截然不同的状态：

- 日常状态：用户查看健康数据、管理设备、学习急救知识，需要平静、清晰和可信。
- 紧急状态：用户可能焦虑、单手操作或替他人呼救，需要最短路径、强反馈和低误触。

界面整体应像一台安静可靠的医疗仪器。红色只在呼救、危险和高风险状态出现，不能成为装饰色。

## 2. 领域语言

- AED 机柜
- 救援路线
- 心电波形
- 手环传感器
- 体检档案
- 响应者信标
- 救援时间轴

项目的标志性视觉元素是“生命线”：用连续脉冲线连接呼救、匹配、接单、抵达和完成状态。

## 3. 色彩系统

| Token | 色值 | 用途 |
|---|---|---|
| `rescue-blue` | `#1F63D5` | 品牌、主操作、链接 |
| `rescue-blue-soft` | `#EAF2FF` | 图标底色、选中背景 |
| `signal-red` | `#E5484D` | SOS、危险、高风险 |
| `signal-red-soft` | `#FFF0F0` | 危险提示背景 |
| `monitor-green` | `#158F63` | 正常、在线、可用 |
| `warning-amber` | `#C77A16` | 维护、提醒、待确认 |
| `instrument-ink` | `#172033` | 主文字 |
| `slate` | `#56627A` | 次级文字 |
| `muted` | `#8994A8` | 辅助信息、占位 |
| `canvas` | `#F4F7FB` | 页面背景 |
| `surface` | `#FFFFFF` | 内容表面 |
| `line` | `#E4EAF2` | 分割线、边框 |

规则：

- 品牌交互只使用医疗蓝。
- 红色绝不用于普通快捷入口或装饰渐变。
- 正常、警告、危险必须同时使用文字或图标表达，不能只靠颜色。

## 4. 字体与数字

- 中文：系统无衬线字体，优先使用设备原生字体。
- 页面标题：40rpx / 700。
- 区块标题：32rpx / 700。
- 正文：28rpx / 400–500。
- 辅助文字：22–24rpx / 400–500。
- 健康数值、距离和时间使用等宽数字：`font-variant-numeric: tabular-nums`。

## 5. 间距与形状

- 基础单位：8rpx。
- 常用间距：8 / 16 / 24 / 32 / 48rpx。
- 小控件圆角：12rpx。
- 按钮圆角：16rpx。
- 卡片圆角：24rpx。
- 弹层圆角：32rpx。
- 深度策略：浅边框加单层轻阴影，不使用多层重阴影。

## 6. 图标规范

- 通用操作使用 `uni-icons`，保证 uni-app 多端一致性。
- 医疗专用图标使用 Health Icons 的 outline 风格。
- 图标默认线宽保持统一；同一区域禁止混用填充、线性和 Emoji。
- 独立图标放入浅色方形容器；与文字同行的图标不添加无意义底色。
- AED 保留 `AED` 文字识别，避免使用含义模糊的心形或闪电符号代替。

禁止：

- 使用 Emoji 充当搜索、位置、电话、档案、车辆、医生等功能图标。
- 用首字母或随意字符模拟设备品牌图标。
- 为每个入口分配一种装饰色。

## 7. 组件状态

每个交互组件必须具备：

- 默认
- 按下
- 禁用
- 加载
- 错误

列表和数据区域必须具备：

- 骨架加载
- 空状态
- 请求失败及重试
- 数据更新时间

## 8. 页面优先级

1. 首页：紧急入口、附近设备、健康状态。
2. 呼救页：防误触、定位、症状、现场图片、提交反馈。
3. 救援详情：生命线时间轴、位置、沟通与取消。
4. 急救地图：固定/移动设备差异、筛选、路线。
5. 健康页：实时数据、趋势、告警。
6. 体检报告：上传、OCR、指标、AI 解读。
7. 科普与个人中心。
