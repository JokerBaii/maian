# 脉安驰援参赛提交清单

## 参赛归类

- 赛事：中国大学生计算机设计大赛
- 大类：软件应用与开发
- 小类：移动应用开发（非游戏类）
- 作品形态：iOS 优先的移动应用，H5 仅用于评审预览

分类依据：[中国大学生计算机设计大赛“软件应用与开发”分类说明](https://jsjds.blcu.edu.cn/gsjs1/jnjsq.htm)。2026 年材料模板以[大赛官网通知](https://jsjds.blcu.edu.cn/info/1045/2013.htm)发布的压缩包为准，提交前应把本项目文档内容迁入当届官方模板，不自行修改模板固定字段。

## 源码提交前检查

- [ ] 运行 `npm ci`、`npm run type-check`、`npm test`、`npm run build:h5`。
- [ ] 运行 `cd server && mvn clean test && mvn clean package`。
- [ ] 用干净 MySQL 8 数据库完成一次 Flyway 全量迁移。
- [ ] `.env`、媒体文件、日志、数据库文件和构建目录不进入压缩包。
- [ ] 不提交地图、OCR、模型、数据库或 JWT 的真实密钥。
- [ ] 数据库中不包含参赛者个人信息、体验账号、模拟救援或健康记录。
- [ ] 三个参演账户在现场环境临时注册并授权，密码不写入文档或源码。
- [ ] 所有截图使用脱敏或现场临时数据，不标注为真实医疗结论。
- [ ] 体检分析页保留“不能替代医生诊断”提示。
- [ ] SOS 真机演示使用明确的非紧急场景，禁止占用真实急救资源。

## 视频建议

总时长建议控制在 5 至 7 分钟：30 秒说明痛点，60 秒展示架构与创新，3 至 4 分钟展示三端闭环，30 秒展示健康报告 OCR，最后 30 秒总结安全边界与落地价值。具体时长、文件大小和命名规则以当届官方通知为准。
