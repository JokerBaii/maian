# 脉安驰援素材清单

当前版本只使用已落地的本地素材，不依赖远程图片或视频。

## 本地素材

- `src/static/illustrations/`：首页原创主视觉。
- `src/static/editorial/`：科普文章本地封面。
- `src/static/icons/entry/`：应用功能 PNG 图标。
- `src/static/icons/tab-*.png`：底部导航图标。
- `src/static/map/`：固定和移动急救设备地图标记。
- `src/static/logo.png`：应用标识及默认作者头像。

所有页面通用操作图标使用 `@dcloudio/uni-ui` 的 `uni-icons`。无引用的 SVG 源文件和不稳定的外链教学视频已从部署版本移除。

第三方库、地图与素材来源见 `docs/THIRD_PARTY_ASSETS.md`。
