# 脉安驰援素材计划

## 1. 素材来源

### 项目原创主视觉

- 当前落地：`src/static/illustrations/rescue-network-hero-light-v1.webp`
- 用途：首页“城市生命网络”首屏
- 生成方式：OpenAI 内置图像生成工具
- 风格：明亮晨光、半 3D 城市模型、医疗蓝救援路线、少量急救红
- 约束：图片内不包含文字、按钮、Logo 或远程依赖

### 通用图标

- 当前落地：`@dcloudio/uni-ui` 的 `uni-icons`
- 用途：搜索、消息、位置、导航、电话、相机、上传、刷新、设置、用户、文件夹
- 原因：已在项目依赖中，适配 uni-app 多端，无需运行时联网加载

### 医疗图标

- 来源：Health Icons
- 地址：https://healthicons.org/
- 仓库：https://github.com/resolvetosavelives/healthicons
- 许可：CC0
- 风格：outline 作为默认，filled 仅用于选中和高优先级状态

### 通用扩展图标

- 来源：Lucide
- 地址：https://lucide.dev/
- 许可：ISC
- 用途：仅在 `uni-icons` 没有对应图标时补充，并转为项目本地资源

### 空状态与说明插画

- 来源：https://undraw.co/search/medical
- 用途：无设备、无报告、无救援记录、绑定失败、网络错误
- 约束：只选用同一套线性扁平风格，统一替换为项目蓝色

## 2. 素材目录规划

```text
src/static/
├── icons/
│   ├── tab/                  # 底栏图标
│   ├── medical/              # AED、急救箱、心率、救护车等
│   ├── map/                  # 固定点、移动点、当前位置、路线
│   └── status/               # 正常、警告、危险、在线、离线
├── illustrations/
│   ├── empty/                # 空状态
│   ├── onboarding/           # 引导说明
│   └── rescue/               # 救援流程说明
├── covers/
│   └── science/              # 12 张科普封面
└── avatars/                  # 默认用户、医生、官方账号
```

## 4. 使用规则

- 素材必须进入本地目录，核心操作不得依赖远程图片。
- 每项第三方素材在 `THIRD_PARTY_ASSETS.md` 中记录来源与许可。
- 一张图只表达一个主要概念，避免装饰性堆叠。
- 科普封面必须保留足够留白供标题和分类标签显示。
- 图片加载失败时显示统一占位图，不回退到 Emoji。
