# 悬浮助手与业务功能自测

日期：2026-10-22。环境：本机 Spring Boot 后端、独立 H2 预览数据库、Chrome。全局 Agent 接入真实 DeepSeek；OCR 关闭。业务检查使用独立测试账号、真实 JWT、接口及持久化状态。浏览器位置由开发工具模拟，穿戴数据通过测试接口录入。

## 当前回归结果

- 114 项前端单元测试、Vue/TypeScript 类型检查通过。
- 后端回归共 82 项，无失败或错误；覆盖真实 HTTP、事务、权限、文件解析和 Spring AI 工具协议。
- 本轮重跑 14 组助手界面检查、11 组真实模型 Agent 流程和 7 组急救专项，均通过，无未处理浏览器异常。
- 63 项操作的标题、确认要求、创建重试策略、对象来源和表单已与重构前逐项比对，前后端白名单一致。

本轮将任务配置、业务调用和文件处理分开，删除两套分发表及重复列表处理。执行器保留排队、账号校验、确认、取消和恢复；模块职责见 [全局执行说明](AGENT_WORKFLOWS.md)。

## 检查范围

| 范围 | 验证行为 |
| --- | --- |
| 悬浮形象 | 鼠标及触摸拖动、吸边、跨页面单实例、浮动挥手、减少动态效果、弹层打开时隐藏 |
| 浮窗与页面 | 最大 320×360px、320px 小屏输入及保存按钮可见、完整助手展开和返回、设置入口高亮、Markdown 列表和表格无横向溢出 |
| 自然对话 | 真实模型回应 Hello、身份与能力追问、感谢；最近三轮普通对话作为上下文，不生成业务写入或虚构完成结果 |
| 设置与联系人 | 仅更新指定设置、非法阈值拒绝、页面同步、连续补填、只保存一次、删除前确认对象、跨账号隔离 |
| 文件与报告 | 原生文件选择、上传读取、私有保存下载、投稿待审核、报告核对后入档、替换文件后重新识别、正常 mmol/L 等单位不被当作异常标记 |
| 连续办理 | 当前页面对象优先、真实列表序号、补充原任务、文字确认和取消、多项操作顺序执行、复用前项记录和文档 |
| 救援 | 真实定位、只读 AED 预览、确认前不占用资源、确认呼救、定位拒绝、地图选点、志愿者各节点、故障换机及设备保管保护 |
| 提醒与复盘 | 明确时间的持久化提醒、审核状态跟进、结束提醒、真实事件复盘、归还评价待办变化、旧结果提示更新 |
| 中断恢复 | 字段、草稿、AI 偏好及文件恢复；已完成操作不重放，未知写入结果禁止直接重试；对象重新校验，旧急救位置失效 |
| 语音与附件输入 | 拖入文档、粘贴图片、语音最终结果进入原指令流程；取消、切账号及迟到事件隔离，拒绝麦克风后仍可打字 |
| 权限 | 普通用户管理操作被拒绝，非参与者无法读取救援或复盘，文件及报告仅本人可访问 |

界面回归的入口查找关闭 AI，以检查确定性导航；错误重试人为返回一次 HTTP 503，Markdown 排版使用固定回复。这些案例与真实模型流程分别运行。语音通过模拟识别事件验证，不代表真实麦克风识别验收。

## 完整业务流程

`test:business` 使用独立账号检查注册登录、角色授权、设置、联系人、健康数据、科普审核发布、文章互动、设备审核、救援换机，以及完整救援与复盘。

救援按接单、取用点、取用、到场、施救、提交完成、求救者确认、归还和评价推进，使用原有业务接口。测试保留救援历史，结束后停用专用设备；引用历史救援的 AED 不强行删除。不会替演示账号归还设备或提交评价。

投稿、报告、文档和联系人测试清理自己创建的记录，避免反复测试污染推荐和演示数据。旧的「【自测】AED 功能说明」资料已在本地预览库设为不可见，保留历史记录。

## 自动检查与复现

先启动预览，环境配置及账号见 [演示环境说明](DEMO_ENVIRONMENT.md)：

```bash
npm run dev:preview
```

代码检查与浏览器专项分别运行：

```bash
npm run type-check
npm test
mvn -f server/pom.xml test
npm run test:preview
npm run test:ui
npm run test:agent
npm run test:rescue-agent
npm run test:workflows
npm run test:inputs
npm run test:business
npm run test:layout
```

浏览器脚本需要 Node.js 22+ 和 Chrome，默认路径为 `/opt/google/chrome/chrome`，可通过 `CHROME_BINARY` 指定。各脚本使用独立临时浏览器配置和测试账号，截图及检查结果保存至 `.cache/preview/qa/`，服务日志位于 `.cache/preview/logs/`。

预览使用固定的类与依赖快照，避免运行期间被其他编译覆盖。Maven test 成功后，可使用 `PREVIEW_USE_COMPILED_CLASSES=true bash scripts/dev-preview.sh --skip-build` 加载最新编译类；需先停止占用预览端口的旧进程。

## 验证边界

- 当前联调使用 H2，未验证 MySQL 实库迁移。
- 未连接真实 OCR。扫描 PDF 无可提取文字时要求补充；检查单图片识别未配置时明确报错并支持人工填写，不生成虚构指标。
- 定位使用真实浏览器 API，但坐标由 Chrome 模拟，未验证实体手机的定位权限和精度。
- 穿戴输入和语音识别事件由测试模拟，尚未验证真实 BLE、麦克风识别准确率或浏览器语音服务在目标网络的可达性。
- 未完成 Android、iOS 真机或微信运行时验收；本轮未生成 APK。
