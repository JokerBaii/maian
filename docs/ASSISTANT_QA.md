# 悬浮助手与业务功能自测

代码回归记录：2026-10-26；OCR 与高德接入验证：2026-10-25。环境：本机 Spring Boot 后端、独立 H2 预览数据库、Chrome。全局 Agent 接入真实 DeepSeek；OCR 与高德通过本机 `.env` 配置。业务检查使用独立测试账号、真实 JWT、接口及持久化状态。本机预览定位固定在杭州，正式构建使用真实 GPS；穿戴数据通过测试接口录入。

## 当前回归结果

- 145 项前端单元测试、Vue/TypeScript 类型检查通过。
- 后端回归共 95 项，无失败或错误；覆盖真实 HTTP、事务、权限、文件解析和 Spring AI 工具协议。
- 急救专项 6 组及真实模型直接跳转（隐私设置、科普中心、急救地图）3 组通过，无未处理浏览器异常。此前的 14 组助手界面检查属于 2026-10-22 基线。
- 真实模型全局流程 11 组通过，覆盖自然对话、设置直接修改、联系人直接保存与删除确认、普通文件上传、文档投稿、报告核对后入档及权限拦截。
- 本轮另跑通真实模型跨模块长流程 10 组，包括序号取消提醒、后台审核跟进，以及双账号通过 Agent 完成接单至 AED 归还；文件输入与页面密度专项各 7 组通过。
- 文档阅读与报告分流新增 6 组浏览器检查通过，普通文档概括、继续追问和后续投稿均使用真实模型与真实业务接口。
- 65 项操作共用任务执行器；模型先理解当前意图，关键词仅用于不可用时的兜底。普通操作取消重复确认，必要确认保留一次。

本轮删除聊天内的旧急救定位、候选查询、提交和专用表单，急救统一使用既有页面；同时合并跨模块分页类型、科普分类与地图状态文案，删除未引用的科普 API 包装。执行器保留排队、账号校验、确认、取消和恢复；模块职责见 [全局执行说明](AGENT_WORKFLOWS.md)。

全项目的设备选点、穿戴解绑、账号缓存、持久化查询和发布配置清理结果见 [项目清理与回归记录](PAGE_QA_REPORT.md)。

## 报告授权与文件回执（2026-10-26）

- Agent 与报告上传页复用健康数据处理授权。首次识别说明百度 OCR、后续报告和 AI 整理用途；拒绝后不启用共享、不外发、不创建报告，可手动录入。
- 同意后使用已经上传的图片继续识别；核对后才由用户保存。授权同步至设置页面，重试无需重新选图，已有授权不重复询问。
- 3 组浏览器专项通过：`node scripts/check-report-consent.mjs`。授权守卫、设置和图片存储使用真实后端，已授权的识别结果为模拟。
- 另用明确标注软件测试用途的虚构检查单调用真实百度 OCR，成功进入核对，确认前未创建健康报告。首次网络握手失败后重测成功；网络错误仍保留原图供重试。
- 普通文件回执只显示一次文件名，精简内部说明并保留下载。文件拖入、粘贴、语音与恢复专项 7 组复测通过。

## 文档理解与报告自动识别（2026-10-26）

- `node scripts/check-document-understanding.mjs`：6 组通过，无未处理浏览器异常。真实 DOCX 上传后由 DeepSeek 概括二分查找代码，继续追问边界变化，再按明确指令复用文件投稿；三个步骤仅上传一次。
- 使用无提示性文件名的虚构 DOCX 报告，按内容自动进入核对，保留 `95 mg/dL` 原始单位；缺少检查日期和机构时留空，不启用健康共享、不提前入档。
- 跨账号、删除后读取均返回 404。服务端重新读取本人原文件；阅读模型只有总结工具，不持有业务写工具，文档里的设置示例未触发操作。
- AI 关闭时仅展示原文摘录；接口失败或空回答明确提示未完成 AI 分析，可沿用已上传文件重试。真实模型首轮曾遇到 TLS 握手与超时，重测完整流程通过；本地原文摘录不计为真实模型成功。
- 普通文档最多向阅读模型提供前 32000 字，超出时明确显示范围。扫描 PDF 无文字时提示改传清晰图片；本轮未实现 PDF 页面转图 OCR。

## OCR 与高德接入验证（2026-10-25）

- 百度凭据通过 OAuth 鉴权；后端从 `.env` 读取配置并自动获取访问令牌，OCR 凭据未传入前端进程。

- 高德 JS SDK 初始化成功；实际步行规划返回 17 个路线点，POI 搜索返回 3 个地点，无未处理浏览器异常。

| 悬浮形象 | 鼠标及触摸拖动、吸边、跨页面单实例、浮动挥手、减少动态效果、弹层打开时隐藏 |

| 救援 | 模型决策后直接跳转急救页、带入现场描述、页面取得位置、一次点击才呼救、不提前占用资源、剧情讨论不跳转、志愿者节点及设备保管保护 |
| 提醒与复盘 | 明确时间的持久化提醒、审核状态跟进、结束提醒、真实事件复盘、归还评价待办变化、旧结果提示更新 |
| 中断恢复 | 字段、草稿、AI 偏好及文件恢复；已完成操作不重放，未知写入结果禁止直接重试；对象重新校验，旧急救位置失效 |
| 语音与附件输入 | 拖入文档、粘贴图片、语音最终结果进入原指令流程；取消、切账号及迟到事件隔离，拒绝麦克风后仍可打字 |

## 完整业务流程

`test:business` 使用独立账号检查注册登录、角色授权、设置、联系人、健康数据、科普审核发布、文章互动、设备审核、救援换机，以及完整救援与复盘。

救援按接单、取用点、取用、到场、施救、提交完成、求救者确认、归还和评价推进，使用原有业务接口。测试保留救援历史，结束后停用专用设备；引用历史救援的 AED 不强行删除。不会替演示账号归还设备或提交评价。

投稿、报告、文档和联系人测试清理自己创建的记录，避免反复测试污染推荐和演示数据。旧的「【自测】AED 功能说明」资料已在本地预览库设为不可见，保留历史记录。

## 自动检查与复现

先启动预览，环境配置及账号见 [演示环境说明](DEMO_ENVIRONMENT.md)：

```bash
npm run dev:preview
```

代码检查与浏览器专项分别运行：

```bash
npm run type-check
npm test
mvn -f server/pom.xml test
npm run test:preview
npm run test:ui
npm run test:agent
npm run test:rescue-agent
npm run test:workflows
npm run test:inputs
node scripts/check-report-consent.mjs
node scripts/check-document-understanding.mjs
npm run test:business
npm run test:layout
```

浏览器脚本需要 Node.js 22+ 和 Chrome，默认路径为 `/opt/google/chrome/chrome`，可通过 `CHROME_BINARY` 指定。各脚本使用独立临时浏览器配置和测试账号，截图及检查结果保存至 `.cache/preview/qa/`，服务日志位于 `.cache/preview/logs/`。

预览使用固定的类与依赖快照，避免运行期间被其他编译覆盖。Maven test 成功后，可使用 `PREVIEW_USE_COMPILED_CLASSES=true bash scripts/dev-preview.sh --skip-build` 加载最新编译类；需先停止占用预览端口的旧进程。

## 验证边界

- 本机联调使用 H2；后续公网部署已在独立 MySQL 8 空库通过 17 个迁移、登录、Agent、文档与 OCR 检查，详见 [部署记录](../deploy/README.md)。
- 已完成真实 OCR 与虚构检查单联调；扫描 PDF 无可提取文字时仍需补充。未配置 OCR 的环境会明确报错并支持人工填写，不生成虚构指标。
- 定位使用真实浏览器 API，但坐标由 Chrome 模拟，未验证实体手机的定位权限和精度。
- 穿戴输入和语音识别事件由测试模拟，尚未验证真实 BLE、麦克风识别准确率或浏览器语音服务在目标网络的可达性。
- 未完成 Android、iOS 真机或微信运行时验收；本轮未生成 APK。
